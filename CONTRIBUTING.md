# Contributions

BlueTeam.News is maintainer-led and does not accept unsolicited pull requests or feature requests. Forks are welcome under the [MIT License](LICENSE).

Focused bug reports are useful when the latest release is reproducibly broken. Before filing one, read [SUPPORT.md](SUPPORT.md), reduce the problem to a minimal case, and remove credentials or sensitive organization data from logs and examples.

Do not report vulnerabilities in a public issue. Follow the private process in [SECURITY.md](SECURITY.md).

If the maintainer invites an external change, the issue or discussion will define its scope, tests, review expectations, and licensing terms.

# Support

BlueTeam.News is a maintainer-led open-source project provided as-is, without a service-level agreement, response-time guarantee, maintenance schedule, or public roadmap.

Before opening a bug report:

1. Confirm the problem occurs on the latest release with Node 22.19+ in the Node 22 line, Node 24, or Node 26.
2. Run `npm install` in the affected clone and restart the server.
3. Review [Operations and deployment](docs/operations.md#troubleshooting) and the process logs.
4. Remove credentials and sensitive organization or threat data from any reproduction.

A focused public issue is appropriate for a reproducible software defect. Include the application version, operating system, Node version, expected behavior, actual behavior, relevant sanitized logs, and minimal reproduction steps. Reports may be closed without action.

Feature requests and unsolicited pull requests are not accepted. Forking and self-hosted use are welcome under the [MIT License](LICENSE).

Report security vulnerabilities privately through [SECURITY.md](SECURITY.md), never in a public issue.

// three views

One evidence pipeline, shaped for different work.

THE BRIEFING optional · Anthropic key required

A daily assessment built from the current signal set.

Generate a BLUF, key judgments, defensive actions, developing situations, convergence, and a 72-hour watchlist on demand. Automatic generation is disabled until an operator enables and configures it in Settings.

The application checks required structure and source constraints, surfaces warnings, and labels the result AI-generated. Operators still verify the content before acting.

/briefing
THE WALL

A passive view for the operations floor.

Rotate through CISA KEV changes, prioritized signals, and the latest saved Briefing without opening another dashboard.

/wall
THE WIRE

Every signal with its score evidence.

Filter by tier, urgency, KEV status, and unread state. Inspect source breadth, CVSS, EPSS, attribution tags, timestamps, and exports.

// quick start

Clone, install, and start.

  1. 1

    Run the local server

    Terminal 
    git clone https://github.com/ryanshrier/blueteam.git blueteam
cd blueteam
npm install
npm start

    Use Node 22.19+ in the Node 22 line, Node 24, or Node 26, then open http://127.0.0.1:3000. The Wall and Wire begin filling as sources respond.

  2. 2

    Choose a view

    Use /wire for analysis or /wall for a passive display. Both work without a third-party API key.

  3. 3

    Optionally enable the Briefing

    Add an Anthropic API key in Settings, or set ANTHROPIC_API_KEY in .env. Generation is billable. If unattended generation is wanted, enable its schedule separately in Settings and choose the time, timezone, missed-run behavior, retries, and attempt limit.

// scoring

The evidence behind priority stays visible.

BlueTeam.News groups related reporting, records source breadth, enriches vulnerabilities with KEV, CVSS, and EPSS data, and scores recency, corroboration, exploitation, severity, and organizational relevance.

fetch → group → enrich → score → retain evidence

Source breadth is not proof of independent reporting, and heuristic matches are not catalog facts. The interface keeps those distinctions inspectable.

// network behavior

Outbound behavior is explicit.

The self-hosted application has no product telemetry, analytics, account, license check, or runtime CDN. It binds to localhost by default.

It fetches configured threat sources and enrichment services. Enabling the Briefing sends selected public-source evidence and configured organization context to Anthropic. A configured webhook receives the selected alert or Briefing fields.

Local state includes SQLite operational data, Markdown Briefings, and a gitignored Settings file. It is not encrypted by the application.
